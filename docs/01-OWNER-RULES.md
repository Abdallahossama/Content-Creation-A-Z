# Owner rules (hard rules first; each one came from real feedback, see `docs/memory/` for the dated source)

## Never
| Rule | Why / source |
|---|---|
| **No women or girls in ANY visual**: photos, paintings, figurines, thumbnails, crowds (crop them out or skip the image). Women may be named in narration only. | Owner hard rule (`memory/no-women-in-visuals.md`) |
| **No AI images, no cartoons as stand-ins.** Real photos, documents, film, maps; stand-in textures are labelled "ILLUSTRATIVE". No AI colourisation. | `real-not-cartoon.md`, `no-ai-slop-design.md` |
| **Copyright-safe only.** US government works (NARA, Army, FBI, NASA), public-domain newsreels, Pexels, Wikimedia PD/CC (credit), incompetech music (CC BY), our own SFX. Never film/TV stills, AP/Getty/Alamy, imgflip memes, commercial music. A `CREDITS.md` per video. | `copyright-safe-only.md` |
| **No graphic content.** Never show executions, gallows in use, dead bodies. One plain line for deaths. No glorifying words (genius, legend, outsmarted). Nazi-era: no swastika-heavy frames and never in thumbnails. | YouTube advertiser rules (research.md §13 in the Göring file) |
| **Never permanently delete** (videos, comments, files). Archive, move, or set Private ("OLD COPY"). Ask the owner to delete their own duplicates. | Standing instruction |
| **Never type passwords/credentials, create accounts, or solve CAPTCHAs.** | Safety |
| **Don't toggle the "altered content / AI" disclosure**; the owner does it. | Owner: "I will do it later by myself" |
| **No text over text** on screen: one text per screen slot; the next replaces the previous. | `edit-notes-last-hours.md` |
| **No 8-bit voice joins** (ffmpeg anullsrc concat); decode to float, insert numpy zeros. | `clean-voice-mix.md` |

## Ask first (and only these)
1. **Downloads:** list file, source, size, licence; wait for OK (a download list in `research/assets.md`).
2. **Thumbnails:** show new or replacement thumbnails (a contact sheet) and wait for OK before uploading or touching an A/B test.
3. **Anything published, sent or deleted that was not asked for.** Posting the prepared pinned comments is pre-approved (rule below).
Everything else: just do it and report the result. The owner wants finished results, not approval loops.
