Studio's schedule time field uses the PC's "Local Time" (Cairo). Until 29 Oct 2026 it showed GMT+03:00 and the rule was "22:00 Cairo = 23:00 field" for Nov/Dec slots. Since Egypt left summer time (29 Oct 2026) it shows GMT+02:00, so **22:00 Cairo = 22:00 in the field**, 19:00 = 19:00. Always zoom on the time-zone chip before scheduling; Egypt summer time returns late April. See [[last-hours-file-keeper-brand]].
