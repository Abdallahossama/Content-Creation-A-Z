# Learned memories

Each file is one rule or fact learned while making the videos: the owner's feedback, the date, **why**, and **how to apply**.
`MEMORY.md` is the index. They are the source behind `docs/01-OWNER-RULES.md`; when a detail is unclear, search here.

To make a new Claude account remember them automatically, copy these files into that account's project memory folder
(`~/.claude/projects/<project>/memory/`), keeping `MEMORY.md` as the index.
