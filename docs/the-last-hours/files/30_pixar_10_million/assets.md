# Pixar: The $10 Million Bet (Mon 3 Feb 1986 → Wed 29 Nov 1995 → Tue 24 Jan 2006 → 2026): visuals DOWNLOAD LIST (nothing downloaded)

Compiled 27 Nov 2026 for **The Last Hours**, folder 30_pixar_10_million (~22-25 min, 16:9). **Nothing has been downloaded to the project.** The owner approves every item.
- **Content checks** were made by eye on contact sheets built in a temp folder outside the project (deleted after): Commons stills at 420 px, and at 900-1000 px for every image with a crowd, a patterned shirt or a busy background (B3, B8, B13, B25, C3). **Pexels clips: 3 frames pulled from the real HD file at 8 %, 50 % and 92 % of the running time** (single-frame remote seeks, no full downloads). "Check" = not settled at that size: open at full size before use.
- **px / size** = Commons API (`imageinfo`); Pexels sizes = HTTP HEAD Content-Length on 27 Nov 2026 (200 OK); resolution/fps/duration from Pexels' own file list. MB = 1,048,576 bytes.
- The **licence** cell names the Commons licence/template. Open the file page and confirm before downloading.
- **dl_assets.py note:** rows A1-A6 are SEC EDGAR text/HTML pages. The Vice City script only keeps jpg/png/pdf/mp4/tif/gif/webp, so it will print `FAIL` for them (harmless). Save those pages by hand ("Print to PDF") or add an `html` case to `kind()` in the copy for this folder.
- LESSONS 38 still applies: before using any clip, make the contact sheet of the exact seconds used.

## How to read this
- **A** = SEC documents (US government, public domain). **B** = people (men only). **C** = places and objects. **E** = Pexels texture/illustrative clips. **X** = excluded.
- "beat" names match research.md chapters (ORIGINS, $10M DEAL, HARDWARE, LUXO, TOY STORY, IPO, STREAK, BREAKUP, IGER/DEAL, SLUMP, 2026).

## Licence key
- **PD** = public domain (US government work, or released by the author). **CC0** = no rights reserved.
- **CC BY x.0** = credit the author (exact string in the credit column) and the licence in the description.
- **CC BY-SA** = credit + share-alike: fine inside the video with credit; **never in the thumbnail**.
- **Pexels licence** = free use, no credit required (we credit anyway in CREDITS.md).

## Access notes
- Commons API answered with "too many requests" at first; a contact-style User-Agent and 2.5 s gaps fixed it. Download Commons files one at a time (the dl script already does).
- Pexels search pages block some clients (HTTP 403 for Node fetch and for a Chrome UA after ~10 searches); the `videos.pexels.com` file URLs below answer `curl -A "Mozilla/5.0"` normally (HEAD 200 on 27 Nov).
- SEC EDGAR needs a User-Agent with a contact address (e.g. `-A "Name research contact you@example.org"`).
- **No 1995 IPO prospectus exists on EDGAR** (Pixar's electronic filings start May 1996). A1 is the first filing that names the IPO date.
