## Access notes
- **NARA:** the Warden's Notebook scans load directly from `https://catalog.archives.gov/medialz/san-francisco/rg-129/296686/Batch0004/Altz_0NNN.jpg` (the `s3.amazonaws.com/NARAprodstorage/...` form returns 403). The catalog page is `https://catalog.archives.gov/id/<NAID>`. The `/proxy/records/search` API now returns the site's HTML to scripts (a bot check, not bypassed). I searched through the catalog page in the browser instead.
- **NPS:** the live gallery files are `https://www.nps.gov/npgallery/GetAsset/<asset-id>` (600 px wide; this is the largest NPS serves for the 1946 set). The older NPGallery items use `https://npgallery.nps.gov/GetAsset/<id>/original.jpg` (1024-1074 px). NPGallery is very slow (30-60 s per image).
  - The old NPS online exhibit (`nps.gov/museum/exhibits/alca/.../1946Escape/`) is gone. Its images and captions survive on the Wayback Machine and are the same 600-px files.
- **HABS on Commons:** the originals are 17 MB TIFFs. To save about 125 MB, take Commons' own JPEG rendering instead: replace the file URL with `https://upload.wikimedia.org/wikipedia/commons/thumb/<a>/<ab>/<FILE>.tif/lossy-page1-2560px-<FILE>.tif.jpg` (about 1-2 MB each; 2560 is a standard Commons step).
- **Internet Archive:** `https://archive.org/download/<item>/page/nN.jpg` redirects to a full-size BookReader image (sizes below are for that redirect).
