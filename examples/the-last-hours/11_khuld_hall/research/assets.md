## THE HALL FOOTAGE: NOT IN THIS LIST (verdict: none)
The 22 July 1979 film (Iraqi state / Ba'ath party) is **excluded, and so are stills taken from it** (Commons "Saddam Hussein during 1979 Ba'ath Party Purge" 1-5). US status depends on whether the tape was ever "published" in 1979 (unprovable); if not, it is protected in the US to about 2099; it may still be protected in Iraq to about 2029; documentary owners (e.g. American Heroes Channel) may hold Content ID references. Full reasoning: research.md section 18. **We tell the hall scene with documents, words and texture, never with its pictures.**

## Access notes
- **AAD:** works in a normal browser; returns 403 to scripts. createpdf links are stable (rid = record id, dt=2776 = Electronic Telegrams 1979).
- **archive.org page images:** `https://archive.org/download/<item>/page/nNN.jpg` redirects to a BookReader image of the stated size. For these FBIS items, n = printed page leaf (checked by eye: e.g. 30 July n30 = page E2).
- **Commons:** API rate-limits bursts (HTTP 429); thumbnails only in standard widths (960, 1280, 1920...). PDF pages render as `.../page5-1280px-<file>.pdf.jpg`.
- **DVIDS:** CloudFront MP4 URLs are public; HD masters need a free DVIDS login (owner's choice; we did not sign in). "HLS" = stream only (fetch with ffmpeg/yt-dlp).
- **cia.gov reading room** was in maintenance on 24 Oct 2026; CREST documents are read from the Internet Archive mirror (same PDFs, same byte counts).
- **Pexels:** some "hd_1920_1080" file names serve 720p; the URLs below are the true 1080p+ renditions.
