Compiled 6 Nov 2026 for **The Last Hours**, folder 23_rasputin_last_night. **Nothing has been downloaded to the project.** The owner approves every item.
- **Content checks** ("check" column) were made by eye on contact sheets at about 420 px (Commons thumbnails) and 360 px (Pexels previews), plus the 3 TNA document images and the NYT front pages at full width. "Check at full size" = small figures were too small to sex at that size: open the original before use; crop or drop if any woman or girl appears.
- **px** = pixel size from the Commons API (`prop=imageinfo&iiprop=url|size|extmetadata`) or, for Pexels / archive.org, read from the JPEG header with a 64-128 KB range request. **size** = HTTP Content-Length from a **HEAD request made 6 Nov 2026**: all 56 Commons URLs returned 200 and matched the API byte size; the 11 Pexels originals, 3 TNA images and 2 archive.org pages returned 200. MB = 1,048,576 bytes.
- **Commons file page** = `https://commons.wikimedia.org/wiki/File:` + the file name shown in the "file" column (spaces → underscores).
- **Licence** = the Commons licence field (LicenseShortName). Re-read the template on the file page before downloading.
- **Rules applied:** PD / CC0 / CC BY only in the safe set; CC BY-SA listed separately (inside the video only, never in a thumbnail); no film or TV stills; no AI images; **no woman or girl in frame; no corpse; no wax figures**.
