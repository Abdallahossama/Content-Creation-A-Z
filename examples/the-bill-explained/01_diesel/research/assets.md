# Ep 01 "Why Diesel Costs $2 More Than Gas": visuals download list

Built 15 Nov 2026. Nothing downloaded yet. 64 candidates, with the BEST 20 marked **★**.

**How each image was checked**
- **Pexels:** each photo page was opened, and the photographer, the original pixel size and the page description/alt text were read. None of the descriptions mention a woman or girl. The images themselves were NOT viewed. Before using any image, look at it full-size and check the background, reflections, posters and ads for women. Drop it if there is any doubt.
- **Commons/LOC:** the licence, author and size were read from the Wikimedia API or the file page.
- **Licences used:**
  - `PX` = Pexels License (free for commercial use, no attribution required, credit given anyway): https://www.pexels.com/license/
  - `PD-US` = US federal government work (NASA, or the LOC Highsmith Archive, which carries no known restrictions)
  - `CC0` = https://creativecommons.org/publicdomain/zero/1.0/
  - `CC BY 2.0` = https://creativecommons.org/licenses/by/2.0/ (the exact credit is required)
- **Pexels direct URL** = the original file. Add `?w=3840` to get a smaller 4K copy.
