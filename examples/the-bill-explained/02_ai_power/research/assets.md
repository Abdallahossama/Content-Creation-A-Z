**How each item was checked**
- **Pexels:** metadata read from each search result's page data (description, title, full tag list, uploader, original size, duration, file list). The MP4 links are the exact file names Pexels lists for the clip. None of the descriptions, titles or tags mention a woman or girl. Only a single thumbnail frame was looked at, not the whole clip. **Before using a clip, watch all of it** and check the background, windows, reflections and screens for women. Drop it if there is any doubt.
- **Pixabay:** the page's VideoObject data was read (uploader, size, duration, keywords). Pixabay labels AI-made clips "AI generated", and the 2 that had that label were excluded.
- **Commons:** the licence, author and size come from the Wikimedia API. Only items marked PD or CC0 are included.
- **Licences:** `PX` = Pexels License (https://www.pexels.com/license/; free, no attribution needed, credit given anyway). `PXB` = Pixabay Content License (https://pixabay.com/service/license-summary/). `CC0`. `PD-US` = US federal government work.

- **Pixabay MP4:** the `_large.mp4` link is the file the page plays (usually 1920 wide). Full resolution comes from the page's Download button.
- People column: `none` = no people in the description or tags. `men` = men are named in the description. `check` = could not be confirmed.
